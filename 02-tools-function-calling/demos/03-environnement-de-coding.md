# 🛠️ Démo 03 - L'environnement d'un Coding Agent

## 🔍 Ce que tu regardes

Le meilleur point de départ pour un agent de code est souvent un cycle très simple :

1. lire l'arborescence ;
1. ouvrir les fichiers utiles ;
1. proposer une petite modification ;
1. lancer les tests ;
1. relire le diff ;
1. résumer ce qui a changé.

## 🧩 À vérifier

- le chemin d'écriture est borné ;
- le shell est limité ;
- les tests sont la source de vérité ;
- le résumé final parle du patch, pas seulement du raisonnement.

## 💡 Message clé

Le bon agent de code n'a pas besoin d'avoir accès à tout. Il a besoin d'accéder au bon
minimum.
