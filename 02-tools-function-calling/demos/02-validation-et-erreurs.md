# 🧪 Démo 02 - Validation et erreurs

## 🔍 Ce que tu regardes

Quand le modèle fournit une entrée invalide, le runtime ne "corrige" pas en silence. Il
refuse, explique, puis laisse le modèle se réajuster.

## 🧩 À vérifier

- erreur de forme : schéma invalide ;
- erreur métier : chemin hors sandbox ;
- erreur de permission : action non autorisée ;
- erreur d'exécution : timeout ou échec de commande ;
- observation réinjectée dans l'historique.

## 💡 Message clé

Une bonne erreur est déjà un feedback pédagogique pour l'agent.
