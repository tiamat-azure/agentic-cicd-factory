# 🎬 Démos - chapitre 02

Ces démos sont des **démos de design**, pas encore un gros agent de production. Elles
montrent comment penser les tools avant de coder l'automatisation.

| Démo | Question posée | Ce qu'il faut observer |
| ---- | -------------- | ---------------------- |
| [`01-tool-contract.md`](01-tool-contract.md) | qu'est-ce qu'un contrat de tool ? | nom, description, schéma, sortie |
| [`02-validation-et-erreurs.md`](02-validation-et-erreurs.md) | que fait le runtime quand ça échoue ? | refus explicite, message utile |
| [`03-environnement-de-coding.md`](03-environnement-de-coding.md) | quel minimum pour un Coding Agent ? | lire, écrire, tester, expliquer |

> Objectif : sortir du flou "le modèle appellera bien ce qu'il faut" et entrer dans un
> design d'environnement contrôlé.
