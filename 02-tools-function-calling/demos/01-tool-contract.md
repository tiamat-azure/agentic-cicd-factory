# 🧰 Démo 01 - Le contrat d'un tool

## 🔍 Ce que tu regardes

Un tool utile n'est pas "une fonction exposée". C'est une interface stable que le modèle
peut reconnaître, sélectionner et appeler sans ambiguïté.

## 🧩 À vérifier

- le nom du tool dit clairement ce qu'il fait ;
- la description explique quand l'utiliser ;
- le schéma borne les arguments ;
- la sortie est exploitable par le tour suivant ;
- les propriétés interdites sont explicitement rejetées.

## 💡 Message clé

Si le modèle hésite entre deux tools, le problème est souvent dans la description, pas
dans le modèle.
