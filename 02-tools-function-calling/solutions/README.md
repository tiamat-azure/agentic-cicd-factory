# 🔑 Solutions - chapitre 02

Ces corrections sont repliées dans le site. Lis-les après avoir essayé.

## 🪜 Exercice 1

Attendus principaux :

- tools de lecture pour explorer ;
- permissions d'écriture bornées ;
- shell limité aux tests et à quelques commandes explicites ;
- réseau désactivé par défaut ;
- outils destructifs non exposés tant qu'ils ne sont pas nécessaires.

## 🧾 Exercice 2

Attendus principaux :

- schémas stricts et petits ;
- descriptions orientées usage, pas implémentation ;
- erreurs courtes, précises, actionnables ;
- aucune ambiguïté sur le périmètre autorisé.

## 📦 Exercice 3

Un bon livrable mentionne :

- le sous-ensemble de tools retenu ;
- la sandbox ;
- la validation avant exécution ;
- la boucle lire → modifier → tester → résumer ;
- la sortie machine-lisible ou textuelle finale.

> La vraie correction n'est pas "quel code exact écrire", mais "est-ce que l'environnement
> rend l'agent sûr, testable et explicable ?"
